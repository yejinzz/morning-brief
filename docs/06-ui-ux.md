# 06 · UI/UX 설계 (UI/UX)

> Morning Brief · 설계 문서 6/8 · 작성일 2026-11-10 · 상태: 초안(승인 대기)

모바일 우선 PWA. 과도한 대시보드·장식보다 **빠른 읽기와 정보 밀도**를 우선한다. 목표: 아침에 5분 이내로 핵심 뉴스 파악.

---

## 1. 정보 구조 (IA)

```
Morning Brief (PWA)
├── 홈 / 브리핑 화면 (기본)
│   ├── 헤더: 날짜 · 생성 완료 시각 · 설정 아이콘
│   ├── 한 줄 브리핑 (오늘의 요약 1~2문장)
│   ├── 요약 통계 바: 수집 N · HIGH N · 예상 N분
│   ├── 탭 바: [전체] 국내시사 · 경제국제 · AI·LLM · 개발인프라 · 기타테크
│   └── 뉴스 카드 리스트 (선택 탭 기준)
├── 날짜 선택 (지난 브리핑)
├── 기사 카드 → 원문(외부 링크, 새 탭/인앱 브라우저)
└── 설정
    ├── 테마 (라이트/다크/시스템)
    ├── 관심 카테고리
    ├── 알림 (권한·구독·해지)
    └── 정보 (버전·무료 운영 안내·마지막 동기화)
```

- **단일 페이지 중심**: 홈이 곧 브리핑. 라우팅은 `/`(오늘), `/d/:date`(지난), `/settings`.
- 하단 또는 상단 탭 1줄로 카테고리 전환(스크롤 가능한 수평 탭).

---

## 2. 화면별 설계

### 2.1 홈/브리핑
- **헤더**: `2026-11-10 (월)` · `07:04 생성 완료` · ⚙️. 생성 시각은 신뢰 신호(언제 만든 브리핑인지).
- **한 줄 브리핑**: 당일 HIGH로 생성. 없으면 숨기거나 "오늘은 중요 뉴스가 적습니다".
- **통계 바**: `수집 42 · HIGH 9 · 약 4분`. 작게, 한 줄.
- **탭**: 전체 기본 선택. 각 탭에 HIGH 건수 뱃지(예: `AI·LLM ③`).
- **카드 리스트**: 선택 탭의 HIGH 기사만(기본). 카테고리 내 `display_order` 순.

### 2.2 기사 카드 (핵심 컴포넌트)
```
┌─────────────────────────────────────┐
│ [AI·LLM]            🔴 HIGH   09:12  │  ← 카테고리 칩 · 영향도 · 발행시각
│ 제목 (2줄까지, 말줄임)                │
│ 요약 3문장 이내 (독자적·짧게)         │
│ ─────────────────────────────────── │
│ 💡 HIGH 근거: …(1문장)               │  ← 판단 근거
│ 출처명 · 원문 보기 →        ✓ 읽음    │  ← 출처 · 외부링크 · 읽음 토글
└─────────────────────────────────────┘
```
- 읽음 처리: 카드 탭/스크롤 완료 시 흐리게(로컬 저장, D-2).
- `evidence_basis='title_desc_only'`이면 "제목·설명 기반 분석" 작은 라벨(환각/근거 한계 투명 표시).
- 원문 링크: 외부 이동(새 탭). 앱 내 재배포 없음.

### 2.3 지난 브리핑
- 날짜 피커(캘린더 또는 리스트). 보관 기간 내(90~180일) 날짜만 선택 가능.
- 데이터 없는 날짜: "해당 날짜 브리핑이 없습니다".

### 2.4 설정
- 테마 토글, 관심 카테고리 멀티선택(기본 탭 정렬에 반영), 알림 권한/구독 관리, 앱 정보.
- 알림 섹션: iOS는 "홈 화면에 추가 후 사용 가능" 안내 노출(설치 안 된 경우).

## 3. 상태 UI (필수 정의)

| 상태 | 트리거 | 표시 |
|---|---|---|
| **로딩** | 데이터 fetch 중 | 스켈레톤 카드 2~3개 |
| **생성 중** | `daily_briefings.status='generating'` | "오늘 브리핑을 준비 중입니다" + 마지막 정상 브리핑 링크 |
| **정상(ready)** | status='ready' | 브리핑 전체 |
| **HIGH 0건** | status='empty_high' | "오늘은 HIGH로 분류된 뉴스가 없습니다" + (선택) MEDIUM 보기 토글 |
| **카테고리 0건** | 해당 탭 HIGH 0 | "이 카테고리의 주요 뉴스가 없습니다" |
| **네트워크 오류** | fetch 실패, 캐시 있음 | 오프라인 배너 + 캐시된 마지막 브리핑 |
| **오프라인/캐시** | SW 캐시 응답 | "오프라인 — 마지막 동기화 07:04" 배너 |
| **생성 실패** | status='failed' | 성공 알림 없음. "최신 브리핑을 불러오지 못했습니다" + 마지막 정상 브리핑 유지 |

- 원칙: **실패를 성공처럼 보이지 않게.** 항상 마지막 정상 브리핑으로 폴백.

## 4. PWA / 설치 / 오프라인

- **매니페스트**: name, short_name(Morning Brief), `display: standalone`, 테마/배경 색, 아이콘(192/512, maskable).
- **서비스 워커**:
  - 앱 셸(정적 자산) 캐시 → 즉시 로드.
  - 브리핑 데이터: 최근 조회분 캐시(stale-while-revalidate). 오프라인 시 캐시 표시.
  - 푸시 수신 핸들러(`push` 이벤트) → 알림 표시, `notificationclick` → 해당 날짜 딥링크.
- **설치 UX**: Android는 설치 배너/버튼. **iOS는 공유→"홈 화면에 추가" 안내**(푸시 전제조건). iOS 16.4+ 필요 안내.
- HTTPS 필수(Cloudflare Pages가 제공).

---

## 5. 푸시 UX

- **권한 요청**: 자동 팝업 금지. 설정/온보딩에서 "알림 받기" 버튼 탭(사용자 제스처) 시 요청(iOS 요구사항).
- **구독**: 권한 허용 → `pushManager.subscribe` → 서버에 구독 저장.
- **알림 내용**: 제목 "오늘의 주요 뉴스 N건", 본문 "국내시사 2 · AI 3 · … · 약 4분". 탭 시 `/d/:date`.
- **해지**: 설정에서 구독 해제 → 서버 비활성화.
- **실패/만료**: 서버가 410 감지 시 구독 정리(사용자 개입 불필요).
- **HIGH 0건 알림(D-1)**: 발송(조용한 알림) vs 미발송 — 승인 요청. 권장: **미발송**(아침 피로 감소) 또는 "오늘은 조용한 날" 선택적.

---

## 6. 디자인 톤 & 접근성

- **톤**: 뉴스 리더. 절제된 타이포, 충분한 대비, 카드 경계 최소화, 영향도 색(HIGH=주의색) 외 장식 색 자제.
- **다크 모드**: 시스템 연동 + 수동. 아침/야간 모두 가독.
- **타이포**: 본문 16px 이상, 제목 가중치 대비. 한글 가독 폰트(시스템 폰트 우선, 외부 폰트 로드 최소화 — 성능·오프라인).
- **접근성**: 의미론적 HTML, 포커스 링, 카드 링크 명확한 레이블, 색만으로 영향도 전달하지 않기(라벨 병기), 터치 타깃 ≥44px.
- **성능**: 번들 최소화, 이미지 지양(텍스트 중심), 지연 로드. 모바일 저사양·저속에서도 빠르게.

---

## 7. 반응형

- 모바일(기본, ~430px): 단일 컬럼 카드.
- 태블릿/데스크톱: 최대 폭 제한(가독), 선택적 2컬럼. 데스크톱 조회 지원하되 모바일 우선.

---

## 8. 결정/확인 필요

- **D-1 HIGH 0건 푸시**: 권장 "미발송". 승인 요청.
- **D-2 읽음 상태**: 로컬 저장(이 문서 전제). 승인 요청.
- MEDIUM/LOW "더 보기" 토글 제공 여부(기본 HIGH만) — 선택 기능, MVP 포함 여부 결정 가능.
