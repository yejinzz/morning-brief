## 8. 핵심 트레이드오프 / 수용 위험 (사용자 확인)

1. **정확한 07:00·무중단 보장 불가** — 무료 플랫폼(GitHub cron 지연·누락, Supabase 중지, 무료 정책 변경) 특성상 베스트 에포트. → 수용 전제(NFR-3). ✅ 사용자 확인 필요.
2. **영구 0원 보장 불가** — 무료 정책 변경 위험. 현재(2026-11) 검증은 통과. → 수용. ✅ 확인 필요.
3. **무료 AI 학습 사용** — 공개 뉴스 메타만 전송으로 완화하나 완전 배제는 유료 전환 필요(하지 않음). → 수용. ✅ 확인 필요.
4. **iOS 푸시 = 홈화면 설치 필수** — 설치 안 하면 푸시 없음(앱 조회는 가능). → 설치 유도 UX. ✅ 확인 필요.
