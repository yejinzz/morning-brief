## 1. 테스트 전략

- **Mock 우선**: 외부(RSS/AI/DB/푸시) 의존은 픽스처·Mock로 CI 자동화. 실서비스는 수동 smoke 최소화(무료 한도·비밀 보호).
- **계약 기반**: AI JSON Schema·API 타입·DB 제약을 테스트로 고정.
- **실패 경로 우선**: 한도 소진·장애·부분 실패·멱등을 happy path만큼 중요하게.
- 도구(제안): 프론트 Vitest/RTL + Playwright(E2E), 파이썬 pytest. M0에서 확정.

## 10. CI 구성

- PR/push: lint + type + unit + 통합(Mock). 외부 비밀 불필요한 범위만 CI 자동화.
- 실서비스 smoke(수동/로컬): 각 마일스톤 완료 시 1회, 결과 보고에 포함.
- 커버리지 목표는 실패 경로 우선(강제 수치보다 시나리오 커버).
